# 🍔 Zingry

Zingry is a modern **food delivery web application** built using **React**, focused on performance, clean UI, and scalable frontend architecture.  
The project simulates a real-world food ordering experience using **mock data** and follows best practices used in production-grade frontend applications.

---

## 🚀 Features

- 🍽️ Browse restaurants and food categories
- 🖼️ Image carousels for food types and outlets
- 🔍 Search and filter restaurants
- 📱 Responsive design for mobile and desktop
- ⚡ Optimized asset loading and clean folder structure

---

## 🛠️ Tech Stack

- **React** (Hooks & Functional Components)
- **JavaScript (ES6+)**
- **HTML5 & CSS3**
- **JSON-based mock API**
- **Git & GitHub**

## 🧪 Mock Data

This project uses **locally created mock data** for development and UI testing.

> ⚠️ Note: Mock API files are intentionally excluded from the repository to avoid committing large or sensitive data.  
> You can create your own mock data structure based on the UI needs.

## 🖼️ Asset Management

- Images are organized by **purpose**, not type
- All assets use **lowercase kebab-case naming**
- Image paths are centralized for maintainability

📦 Installation & Setup

# Clone the repository

git clone https://github.com/viplav-kumar/zingry-app.git

# Navigate to project folder

cd zingry-app

# Install dependencies

npm install

# Start development server

npm start
